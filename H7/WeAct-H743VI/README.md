Продвинутая плата с камерой и много флеша для программы и ОЗУ.

https://github.com/WeActStudio/MiniSTM32H7xx

При отладки из ОЗУ программа первоначально стартует по адресу 0x24000000, поэтому делаем так

```
	if ((retPCasm() & 0x24000000) != 0)
	{
		*((uint32_t *)0xe000ed08) = 0x24000000; /* FlagDebugInRAM=1;*/
	}
```
