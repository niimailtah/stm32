# OLED SH1106

Подключаем SH1106 к STM32G4

### Соединения

При подключении по SPI:

G микроконтроллера к GND дисплея
3V3 микроконтроллера к VCC дисплея
A5 микроконтроллера к SCK дисплея
A7 микроконтроллера к SDA дисплея
A2 микроконтроллера к DC дисплея
A3 микроконтроллера к RES дисплея

CS дисплея не задействован, используется только одно устройство на SPI (низкий уровень CS говорит об этом)
