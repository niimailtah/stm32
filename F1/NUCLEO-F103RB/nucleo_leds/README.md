# Эксперименты с NUCLEO (F103RB)

## Плата со светодиодами

Есть такая плата, на которой просто распаяны светодиоды с токозащитными сопротивлениями. Предназначена она для проверки портов ввода-вывода.
Конечно, изначальна эта плата сделана для Arduino, но и в случае с NUCLEO ее тоже можно использовать.

## Распиновка на NUCLEO 

GND - GND
D13 - PA5
D12 - PA6
D11 - PA7
D10 - PB6
D9  - PC7
D8  - PA9
---------
D7  - PA8
D6  - PB10
D5  - PB4
D4  - PB5
D3  - PB3
D2  - PA10
D1  - PA2, не получилось моргать, т.к. эти пины жестко присоедены к USART2
D0  - PA3, не получилось моргать, т.к. эти пины жестко присоедены к USART2
