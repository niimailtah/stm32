# Эксперименты с NUCLEO (F103RB)

## UART

### USART2
Плата имеет соединение VCP с USART2, поэтому сделал эхо через имеющийся канал (USB на плате)

### USART1
Для проверки USART1 использовал USB-даптер USB-TO-TTL на микросхеме CH343 (в Win драйвер определился как USB-Enhanced-SERIAL CH343).
Pins:
PB6 (USART1_TX) - RXD
PB7 (USART1_RX) - TXD
GND             - GND
VCC (3V3)       - VCC
Переключатель на адаптере на 3.3V
Программа пересылает эхо кроме USART2 еще и в USART1. Запустил 2 терминала: в одном посылаем символ, здесь же получаем эхо, а также получаем этот сигнал во втором терминале.
