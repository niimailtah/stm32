# ST-LINK V2

Следует обратить внимание, что распиновка SWD отличается от плат производства не WeAct!!!

# Заметки

Режим опроса (блокирующий, blocking mode). В качестве приемника использовал модуль Silicon Labs CP2102 USB to UART Bridge и терминал by Br@y++

Switches:
USB ON
485 OFF
232-485 переключатель в этом положении

Pins:
TXD - A10 (USART1_RX)
RXD - A9  (USART1_TX)
GND - GND
