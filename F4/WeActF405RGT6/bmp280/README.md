# BMXX80
Тестирование датчиков давления/температуры

### Соединения

#### BMP280

I2C канал 2
| WeAct | BMP280 |
| ----- | ------ |
| 3V3   | VCC    |
| GND   | GND    |
| PB10 SCL | SCL |
| PB11 SDA | SDA |
| 3V3         | SCB |
| GND или 3V3 | SDO |
Для того, чтобы BMP280 перешел в режим I2C следует SCB соединить с 3V3 (иначе BMP280 будет работать в режиме SPI, ??? проверить!) 
SDO задает I2C адрес: GND - 0x76, VCC - 0x77. Если не подсоединять, то считает, что подключен к GND (0x76).

#### BMP180

I2C канал 2
| WeAct | BMP180 |
| ----- | ------ |
| 3V3   | VCC    |
| GND   | GND    |
| PB10 SCL | SCL |
| PB11 SDA | SDA |
I2C адрес: 0x77

#### USART

Используется для логирования и вывода данных. Соединяем с Mini Debugger.

PA10 USART1_TX
PA11 USART1_RX

#### SWD

Используется для отладки и прошивки. Соединяем с Mini Debugger.

PA13 SWCLK
PA14 SWDIO

#### Примечания

Для отмеривания времени используется таймер TIM1.
