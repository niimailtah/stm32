# Black STM32F407VET6

Проект bootloader-а с CLI и 2мя приложениями:
- 1е приложение: UART Shell для работы с внешней Flash (по SPI)
- 2е приложение: UART Shell для работы с внутренней Flash (NVRAM)

## Прграммирование и уведомления
Для проекта используется [WeAct Mini Debugger](https://github.com/WeActStudio/WeActStudio.MiniDebugger). Программирование производится через SW, уведомления - UART Shell     
Для индикации процесса работы (heart beat) используется светодиод на PA6 и таймер TIM4: `Bootloader` - 1 раз/сек, `ExtFlashApp` - 2 раз/сек, `IntFlashApp` - 3 раз/сек
Планируется светодиод на PA7 использовать для индикации чего-либо внутри приложений.

## UART Shell
Используется UART1: PA10, PA9

## TIM4
Используется для индикации heart beat
| PSC     | AutoReload | Частота | App |
| ------- | ---------- | ------- | --- |
| 28000-1 | 3000       | 2 Гц    | Bootloader  |
| 28000-1 | 2000       | 4 Гц    | ExtFlashApp |
| 28000-1 | 1000       | 6 Гц    | IntFlashApp |
168_000_000 / 28000 = 6000

## Реализация
Проект реализуется с помощью 6 проектов: 3 приложения и 3 библиотеки.

Приложения объеденены в одну папку `Flash`
1) `Bootloader`
2) `ExtFlashApp`
3) `IntFlashApp`

Для того чтобы объеденить проекты пока что поступал следующим образом: создаем проект, копируем внутрь `Flash`, в Cube выбираем контекстное меню `Configure->Configure and Detect Nested Projects...`. 
Проектов с одинаковым именем не должно быть в workspace.

Библиотеки объеденены в одну папку `Libraries`
1) `shell`
2) `memory`
3) `nvram`

Для объединения нескольких библиотек поступаем тем же образом как и с прилрожениями (создаем, копируем, ...).  
Для создания библиотеки следует на последнем шаге мастера выбрать цель static library.  
Для того, чтобы в каком-либо проекте были видны прототипы функций библиотеки следует включить пути для include-файлов.  
Для линковки следует указать используемые в приложении библиотеки. В контекстном меню проекта выбираем Properties, раздел C/C++ General -> Path and Symbols, вкладка References и галкой отмечаем нужное.
