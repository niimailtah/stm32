# Black STM32F407VET6

Пробуем записывать/читать/стирать внутреннюю Flash

### Соединения

Для показа дампа памяти будем использовать USART1 (PA9, PA10).
Также весь вывод STDOUT переправлен в USART1.

### Управление

Подключаемся по UART и набираем текст для записи во flash. Конец ввода происходит по нажатию Enter или по достижению длины ввода в 64 символа.
Пока что не получилось заливать данные по UART.
Попробовал залить данные по нажатию кнопки, и вот тут все прошло успешно.

### Индикация и уведомления

Индикация осуществляется светодиодами D2.
D2 подключен к таймеру и сигнализирует о работоспособности платы.
