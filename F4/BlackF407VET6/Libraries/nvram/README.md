# NVRAM

Сохранение значений в энергонезависимоу памяти

## Summary
Для сохранения можно использовать Flash, но неудобно. Изменение значений можно прлизводить только после стирания, а стирать можно только блоками (страницами/секторами).  
Попытаемся организовать память так, чтобы минимизировать стирания страниц/секторов.  
Для считывания значения требуется сначала найти положение актуальной ячейки, а потом уже прочитать ее. Если использовать фиксированный размер ячейки, то переменную можно найти по ID.  
Но размер ячейки не всегда одинаковый (например, значение структуры), поэтому придется организовать ячейки с переменной длиной. Отсюда возникает задача быстрого поиска (самое простое - двоичное дерево).
