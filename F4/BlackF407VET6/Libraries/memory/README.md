## Внешняя flash

Пробуем записывать/читать/стирать внешнюю Flash

### Соединения

На плате W25Q16 подключена к SPI1 в альтернативной конфигурации:

| SPI1 | STM32pin |
| ---- | -------- |
| SCK  | PB3      |
| MISO | PB4      |
| MOSI | PB5      |

Ножку PB0 назначим как выход выбора W25Q16 в аспекте работы SPI (CS нога).

### Управление
Кнопкой K1 читаем из Flash.  
Кнопка K2 меняет первые 4 байта памяти. А если память уже была изменена, то повторное нажатие стирает страницу (записывает 0xff).

### Индикация и уведомления
Индикация осуществляется светодиодами D2 и D3.  
D2 подключен к таймеру и сигнализирует о работоспособности платы.    
D3 загорается перед началом любой операции (чтение/запись/стирание) и гаснет после завершения.
