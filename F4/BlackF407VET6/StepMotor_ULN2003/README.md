# STM32F407VET6

## Шаговый двигатель с драйвером NL2003A

#### Подключение

| STM32 Pin | UNL2003A |
| --------- | -------- |
| PA2       | In1      |
| PA3       | In2      |
| PA4       | In3      |
| PA5       | In4      |
| 5V        | VCC      |
| GND       | GND      |
Питание подводится от `MiniDebugger`

SWD - `MiniDebugger`  
UART1 - `MiniDebugger`
