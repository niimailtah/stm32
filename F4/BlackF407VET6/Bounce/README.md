# Black STM32F407VET6

Реализация устранения дребезга кнопки с помощью таймера.  

Алгоритм следующий:
- есть глобальная переменная состояния
- на пин кнопки подключено прерывание
- по приходу этого прерывания производится переключение переменной состояния и запуск таймера
- когда время таймера заканчивается проверяется состояние пина кнопки и, если оно не изменилось, тогда переключаем значение переменной состояния и останавливаем таймер

Если таймер настроен на режим `OnePulse`, то останавливать таймен не нужно.

### Индикация и уведомления

Индикация осуществляется светодидом D2.
