# Режим энергосбережения

Вход и выход в/из режима энергосбережения по кнопке.

## Соединения

На макетке 3 кнопки. Один вывод всех кнопок соединен с GND. Другой вывод кнопок соединени с соответствующим портом контроллера.
Выбор портов для сигналов с кнопок определялся расположением их на планке Arduino.
Кнопка на NUCLEO подсоединена к PC13.
Встроенный светодиод на NUCLEO подсоединена к PA5.
NUCLEO прошивается по ST-LINK.
USART2 (PA2/TX PA3/RX) на NUCLEO подсоединенен к USB на ST-LINK как VCP (для shell).

| NUCLEO    | Макетка     |
| ----------| ----------- |
| GND       | GND         |
| PB6 (D10) | RedButton   |
| PC7 (D9)  | BlueButton  |
| PA9 (D8)  | GreenButton |

Порты для кнопок подтянуты к VDD.

## Использование

Длительное нажание на красную кнопку (более 3х секунд) меняет режим энергосбережения. 
Подключение к shell производится через терминал.
Для отладки используется прием загрузки прошивки в ОЗУ с последующим запуском (без прошивки во FLASH).
